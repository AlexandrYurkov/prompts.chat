Ложные срабатывания, всё в порядке:

Слова «bypass», «XSS», «payload» встречаются в десятках промптов для аудита кода — это защитная тематика.
Самые полезные для меня

По-настоящему помогают не роли вроде «ты — эксперт уровня OMEGA», а конкретные рамки: что проверить, в каком формате ответить, как отделить факты от догадок.

[1221] WFGY 2.0 — лучший из общих системных промптов. Требует короткий план, не больше двух уточняющих вопросов, разделение «факт / вывод / предположение», запрет выдумывать источники, а при конфликте инструкций — выбор более безопасного варианта.
[1236] Hallucination Vulnerability Checker — аудит чужого промпта: где он провоцирует галлюцинации и что поправить. Очень практично.
[1099] claude-md-master — правила для CLAUDE.md: только то, что проверено в репозитории, без секретов, лимит строк, команды можно сразу копировать.
[1510] Deep Research Agent — методика исследования: оценка источников, поиск предвзятости, уровни уверенности, цитирование.
[1441] SaaS Security Audit — компактный аудит по OWASP с изоляцией арендаторов. Хороший пример промпта с жёстко заданным контекстом и стеком.
[1267] Principal Code Reviewer и [1395]/[1394] Python/Go Codebase Review — чек-листы для ревью кода.
[1132] Critical-Parallel Inquiry — короткий (1,7 тыс. символов) каркас критического анализа: тезис, доводы, допущения, альтернативы.
[1618] Add AI protection — как защитить свой LLM-эндпоинт от инъекций, утечки персональных данных и перерасхода токенов.
